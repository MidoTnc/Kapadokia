# 카파도키아 벌룬 확률 — 배포본

로컬 HTML 파일과 **완전히 같은 앱**입니다. 차이는 하나: GitHub Actions가 매일 자동으로 운항 여부를 수집해
`data/log.json`에 쌓고, 앱이 그걸 같은 출처에서 읽어옵니다. 브라우저를 안 열어도 데이터가 계속 쌓입니다.

## 왜 배포가 필요한가

브라우저는 다른 도메인의 HTML을 자바스크립트로 읽지 못합니다(CORS). 로컬 파일 버전은 공개 프록시를
경유해 시도하지만 프록시는 자주 막히고 느립니다. GitHub Actions는 서버에서 돌기 때문에 이 제약이 없습니다.

## 설치 (10분)

1. GitHub에서 새 저장소를 만듭니다. 이름은 아무거나 (예: `cappadocia-balloon`).
2. 이 폴더의 내용을 통째로 업로드합니다. 구조는 그대로 유지해야 합니다:

   ```
   index.html
   data/log.json
   scripts/scrape.mjs
   .github/workflows/daily.yml
   ```

3. 저장소 **Settings → Pages** → Source를 `Deploy from a branch`, 브랜치는 `main` / 폴더는 `/ (root)`로 지정합니다.
   몇 분 뒤 `https://<아이디>.github.io/<저장소이름>/` 에서 열립니다.

4. 저장소 **Settings → Actions → General** → 맨 아래 *Workflow permissions*에서
   **Read and write permissions**를 켭니다. (수집 결과를 커밋해야 해서 필요합니다.)

5. **Actions** 탭 → `벌룬 운항 기록 수집` → **Run workflow**로 한 번 수동 실행해 정상 동작을 확인합니다.
   이후에는 매일 07:00 UTC(이스탄불 10:00)에 자동으로 돕니다.

## 로컬 기록을 옮기려면

로컬 파일 버전에서 **JSON 내보내기** → 받은 파일의 `log` 내용을 `data/log.json`의 `log`에 합쳐 넣고 커밋하세요.
배포본을 열면 서버 기록이 자동 병합됩니다.

## 기록 우선순위

높은 쪽이 낮은 쪽을 덮어씁니다.

| 출처 | 뜻 |
|---|---|
| `manual` | 사람이 앱에서 직접 클릭해 넣음 — 무엇도 덮지 못함 |
| `official` | 공식 발표를 확인해 손으로 넣음 |
| `scrape` | 상태 사이트에서 읽어온 값 (`agree:false`면 사이트끼리 엇갈렸다는 뜻) |
| `auto` | 실제 관측 기상으로 추정한 값 — 검증용 정답으로는 약함 |

## 시작 데이터

앱에는 balloonstatus.com의 공개 기록에서 뽑은 **실측 라벨 46일**이 이미 들어 있습니다
(2026-07-05 ~ 08-26 공식 판정 구간). 그중 16일이 취소로, **실측 취소율 34.8%**입니다.
7/14~20 등 그쪽도 기상으로 추정한 구간은 `auto`로 분리해 학습에서 뺐고,
표기가 엇갈린 8/27은 아예 넣지 않았습니다.

이 46일 덕분에 앱은 첫 실행부터 **모델 검증** 패널에서 자기 성적을 채점합니다.
`취소일 적중률`이 핵심 숫자입니다 — 이게 낮으면 그 모델은 "웬만하면 뜬다"고만 말하는 셈입니다.
라벨이 쌓이면 로지스틱 회귀로 계수를 다시 학습하고, **교차검증에서 기존 규칙을 이길 때만** 교체합니다.

## 주의

- 상태 사이트는 구조가 바뀌면 판독이 깨집니다. Actions 로그에 `판독불가`가 계속 찍히면
  `scripts/scrape.mjs`의 `verdict()` 정규식을 손보세요.
- Open-Meteo 무료 티어는 비상업용입니다.
- 표시되는 확률은 **기상 조건 기반 추정**이며 공식 발표가 아닙니다.
  운항위원회 재량·슬롯 제한·사고 후 중단은 날씨로 예측되지 않습니다.
- 여행 블로그에 도는 계절별 취소율(가을 15~20% 등)은 실측과 맞지 않습니다.
  2026년 7~8월 실측 취소율은 34.8%였고, 이는 연평균(220일 운항 = 취소 39.7%)과 큰 차이가 없습니다.
  **여름이 안전하다는 통념은 근거가 약합니다.**
